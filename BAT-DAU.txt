EDUMANAGER – BẮT ĐẦU TẠI ĐÂY
Phiên bản 0.9.0, bộ tích hợp để nghiệm thu.

A. DÙNG TRÊN MÁY TÍNH, CHƯA CÓ SUPABASE
1. Giải nén ZIP (không chạy trực tiếp trong cửa sổ ZIP).
2. Cài Node.js 24 LTS từ nodejs.org nếu máy chưa có.
3. Nhấp đúp START-LOCAL.cmd. Không cần PowerShell.
4. Chờ xuất hiện EduManager LOCAL rồi mở:
   http://127.0.0.1:5173/#/local-setup
5. Tự tạo Admin, đăng nhập và bắt đầu nhập dữ liệu.
6. Giữ cửa sổ chương trình mở trong lúc dùng. Ctrl+C để dừng.

Dữ liệu lưu trong work/local-data, không nằm trên GitHub.
Không có dữ liệu mẫu hoặc mật khẩu mặc định.
Lần cài thư viện đầu tiên cần Internet. Không xóa work/local-data khi cập nhật.

B. ĐƯA LÊN WEBSITE GITHUB HIỆN TẠI
1. Đọc docs/DEPLOY-FINAL.md.
2. Tạo Supabase và dán SQL/Edge Functions đã chuẩn bị.
3. Upload nội dung thư mục mã nguồn lên repository edumanager.
   Upload các thư mục src, supabase, scripts, tests, docs, .github và các file ở gốc.
   Không upload file ZIP thay cho mã nguồn. Không upload node_modules hoặc work.
4. .github/workflows/deploy.yml phải tồn tại; đây là file thường bị bỏ sót.
5. Điền 2 GitHub Variables công khai, chạy workflow, rồi đăng nhập trên website.

Bộ ZIP chưa được tự động đưa lên GitHub hay Supabase của bạn.
Cần nghiệm thu trên project thật trước khi dùng cho vận hành chính thức.
